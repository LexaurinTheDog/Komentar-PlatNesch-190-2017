# Komentář k vyhlášce č. 190/2017 Sb., k provedení § 3 odst. 3 insolvenčního zákona (vyhláška o platební neschopnosti podnikatele)

Otevřený komentář k vyhlášce o platební neschopnosti podnikatele — § po §: doslovné znění, výklad, zmocnění a jeho meze, kazuistika, protiargumenty a praktický závěr; výkaz stavu likvidity a výhled vývoje likvidity, požadavky na zpracovatele, strana majetku a závazků, koncern, sporné závazky a věrohodnost výhledu.

Konsolidované znění: dokument e-Sbírky `SB-2017-00190_2017-07-01`.
